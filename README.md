# 表格任务自动化

**简体中文** | [English](README_EN.md)

> 将一次人工完成的表格处理，沉淀为可验证、可重复运行、可持续升级的任务模板。

`spreadsheet-workflow` 是一个面向非技术用户的通用 Agent Skill。用户只需提供一张或多张源表，以及人工确认正确的历史结果；Agent 会协助识别字段关系和业务规则、处理必要的歧义确认，并生成可重复执行的脚本或 DSL。

它适合每周、每月或每批次重复发生的表格任务，例如多表关联、字段转换、分类汇总、结果模板填充等。Skill 本身不内置考勤、财务、销售等领域规则，实际规则始终来自用户提供的样本与确认。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 引导式规则发现 | 从源表、人工正确结果和可选空白模板中推导候选规则，只询问真正影响结果的歧义 |
| 确定性重复执行 | 将确认后的流程固化为脚本或带固定运行器的 DSL，日常运行不再临时猜测规则 |
| 结构变化检测 | 每次运行重新检查输入和模板结构，发现列、工作表、合并区域等变化时停止并提示优化 |
| 可验证交付 | 回放历史样本，报告逐单元格差异、关键汇总、未匹配记录和异常情况 |
| 安全版本升级 | 纠错或规则变化时创建新版本，保留旧版本并回放已确认案例后再建议切换 |
| 本地数据边界 | 默认在当前工作区保存任务模板和运行记录，不覆盖源表、历史结果或空白模板 |

## 工作方式

### 1. 创建任务模板

提供历史输入与人工正确结果后，Agent 会：

1. 识别每个文件的角色、工作表结构和字段含义；
2. 推导关联、筛选、计算、布局和写入规则；
3. 请用户确认重复记录、空值、舍入、优先级等关键口径；
4. 生成可执行版本并回放历史样本；
5. 保存任务模板、验证结果和仍需关注的异常。

单个历史正确案例只能证明当前规则通过了这次回放，因此首个通过验证的版本会标记为 `TRIAL`，不会被描述为已经完全稳定。

### 2. 运行任务模板

以后处理新一批文件时，Agent 会定位已有任务模板，检查输入结构，并运行已经固定的版本。每次执行都会生成新的结果文件和运行报告，不覆盖原始文件。

### 3. 优化任务模板

当业务规则、表格结构或正确口径发生变化时，Agent 会基于用户的纠正创建新版本，回放可用的历史案例，并保留旧版本用于审计和回滚。

## 快速开始

在 SkillHub 安装后，可在支持 Agent Skills 的 Agent 中调用：

```text
$spreadsheet-workflow

我有几张源表和一份人工确认正确的历史结果表，
请帮我创建一个以后可以重复使用的表格任务模板。
```

第一次创建时，建议准备：

| 材料 | 是否必需 | 用途 |
| --- | --- | --- |
| 一张或多张历史源表 | 必需 | 确认输入结构与数据关系 |
| 人工确认正确的历史结果表 | 建议提供 | 发现规则并进行回放验证 |
| 空白结果模板 | 可选 | 保留指定版式、公式和工作簿对象 |
| 字段含义与验收标准 | 按需确认 | 消除样本无法回答的业务歧义 |

没有人工正确结果时仍可保存 `DRAFT` 版本，但 Agent 不会宣称规则已通过验证。

## 适用边界

适合：

- 同类表格会持续重复处理；
- 结果需要遵守明确且可执行的规则；
- 希望保留验证证据、运行记录和版本历史；
- 表格任务包含多表关联、计算、筛选或模板写入。

不适合：

- 没有复用需求的一次性探索分析；
- 只有自然语言描述、又无法确认关键业务口径的任务；
- 期望 Skill 自带某个行业的固定业务规则。

## 任务模板与数据

生成的任务模板默认保存在当前业务项目中：

```text
.table-workflows/<workflow-id>/
```

该目录可包含规则实现、结构指纹、依赖锁、历史案例、运行报告和版本记录。它属于用户自己的业务项目，不属于本 Skill，也不应在含有敏感数据时公开提交。

## 手动安装

本仓库根目录就是完整的 `spreadsheet-workflow` Skill。将 `SKILL.md`、`agents/` 和 `references/` 复制到以下任一目录：

```text
# 单个项目
<target-project>/.agents/skills/spreadsheet-workflow/

# 当前用户
~/.agents/skills/spreadsheet-workflow/
```

在 Codex 中，也可以让 `$skill-installer` 从本仓库地址安装。
