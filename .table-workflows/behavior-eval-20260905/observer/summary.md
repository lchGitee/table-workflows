## 独立产物证据

主审对 S2、S4R、S5A、S5B 的真实输出全部有值单元格分别比对冻结 discovery、heldout、oneoff、heldoutV2，均一致。S4 原始失败回执与恢复分支分开保留。最终审计确认 7 个 Skill 文件和 6 个输入材料文件未修改，v0001/v0002 共 12 个版本文件哈希不变，v0003 的 5 个声明产物哈希一致。

操作 Agent 多次披露未完成完整 Schema 自动校验；主审最后对当前及 3 份版本 manifest 补做机器校验均通过。应区分“最终文件通过主审校验”与“操作 Agent 自主执行了校验”，后者未发生。

## 需单列的不足与归因

S2 README 的“已确认口径”混合了用户明确确认的筛选规则、从样本推断的排序与版式、未经询问的异常规则。主目的通过不等于所有隐藏政策确认或验证通过；此为确认来源表述不足。名称是 Agent 提议，persona 可接受，不单独认定失败。

S4 的实际阻断首先是生成实现的结构识别行为问题；是否源于 Skill 指导缺口需另行对照具体指导和实现，不能直接归因于 Skill 没有业务规则。保留无关 Excel 关系 Id 的容忍度是结构复用问题，与仓库统计业务口径无关。操作 Agent 如实报告并未绕过检查是正面行为，但仍不满足首次复用要求。

S5B 合成状态例把未询问的“已取消且已收款”排除，README 也说其他状态不计入；冻结口径要求未知发货状态停止核对。该扩展不应计为测试通过覆盖，应单列为异常口径获取不足：隐藏政策与自设测试口径不一致，但隐藏政策此前未提供给操作 Agent，不能称为违反用户已明确的指令。未实际测试缺失字段、零/负数/小数等全部隐藏边界，不能把主流程正确扩张成完整业务可靠。

生效范围文档明确升级后运行采用新版、保留旧结果，最终答复明确本批按新规则计算；但没有用户确认历史重跑行为，也没有验证按业务批次选择旧版。保留历史文件与保存旧版本不等于自动维持旧批次重跑口径。

## 交互成本与测试限制

额外模拟用户答复数：S1 为 2，S2 为 1，S3 为 1，S4R 为 1，S5A 为 0，S5B 开场后为 0，S5C 为 1。未达到任何场景的 8 次上限。主要提问针对必要缺口，未重复索要已有文件；S1 的试算候选始终未冒充已确认规则。S5C 是看到 S5A 措辞局限后、在执行前补定标准的独立分支，有现成修正版作为本地历史，不宣称无历史情况下同样表现。

这是一套简单订单件数汇总的合成场景、一种非技术文员 persona、一批人工正确发现样本及一批隐藏新输入。共享文件系统的隔离依赖读取约定，不是强制沙箱。观察者依主审转发原文，不应宣称覆盖所有工具轨迹或人类真实使用差异。复杂 Excel 样式/对象保留、跨机器环境迁移、大数据性能、多业务泛化、成熟稳定模板晋级均未获得本轮通过证据。模板保持 TRIAL 符合现有证据强度。
