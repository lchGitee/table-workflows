当前默认版本：v0003；状态：TRIAL（试用）。已通过 1 批人工确认历史样本和 9 项候选运行验证，尚无独立月份人工正确结果。v0001、v0002 及其快照完整保留。

## 当前规则

计入所有发货状态恰好为“已发货”的订单，以及发货状态恰好为“待发货”且收款状态恰好为“已收款”的订单。已发货订单的收款状态不影响计入，每笔订单只计一次；其他状态不计入。按仓库代码升序汇总件数，沿用“汇总”工作表和“仓库代码 / 发货件数”两列。

用户已明确要求“以后”采用新口径，从升级后的运行开始生效；原有结果文件保留。此前 W01 从 4 改为 6 是一次性人工调整，不进入长期规则。该修正版及其回执仍在 runs 中。

订单号缺失或重复时停止；符合计入条件的订单若仓库缺失或件数无效，同样停止，交由人工确认。

## 下次怎么用

提供同样格式的新原表，并说：“用月度仓库发货汇总处理这张表。”无需再提供人工结果或空白模板。

Agent 读取根目录 manifest，按其中的 implementation.command 数组运行固定版本；将唯一的 {request} 替换为新的绝对请求路径。运行请求参考 [current-month-v0003.json](runs/current-month-v0003.json)，版本为 3。输出必须使用新路径，不得覆盖原表、人工结果或已有结果。

每次运行重新提取本次原表的结构并比较指纹。数据值、记录数、样式、尺寸、文档属性及绑定不变的关系 Id 允许变化；表头、工作表、隐藏行列、合并、公式、命名区域、对象或实际关系变化会阻断。运行环境发生变化也需先验证。
