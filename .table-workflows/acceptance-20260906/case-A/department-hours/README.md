版本 v0001，状态 TRIAL。已通过 1 个用于发现规则的历史案例，尚未有独立业务批次验证。

## 固定政策及来源

用户确认仅统计状态等于「已确认」的记录。负工时按负号参与汇总，零工时也计一条。撤回记录不计。只显示有有效记录的部门，按部门编号升序排列。用户原话保存于上级目录 dialogue.md。

未知状态、重复记录编号、缺少编号、工时非有效数值均暂停，请用户确认。不会自动补值、去重或修改长期规则。本版本不做业务舍入，使用十进制求和后输出数值。

输入为一份 .xlsx，工作表「工时明细」，第一行依次为记录编号、部门编号、工时、状态。输出沿用保存的结果表结构，仅填充「部门汇总」A2:C1048576；标题及其他单元格受保护。结构变化、实现或锁定依赖变化均在输出前阻断。
