# 服务计划回填

当前版本 v0001，首次历史回放通过后为 TRIAL。只有 1 个用于发现规则的历史案例，尚未经独立批次验证。

按项目编码匹配源表“需求”，仅回填保存模板“计划表”的 C4:C6。重复编码或未知项目停止；模板项目缺少需求填 0。单价、普通文字、公式、合并与格式保留。政策来自 dialogue.md 中用户实际确认，不能由单批样本推断。

下次说“运行服务计划回填”，提供新源表即可；沿用 templates/template.xlsx。Agent 应创建新的运行请求 JSON，再按 manifest.json 的 implementation.command 执行并替换唯一的 {request}。必须使用绝对路径和新的输出文件路径。不得修改固定版本脚本，也不得临时猜测新规则。

本版本仅支持当前固定三行结果模板。模板文字、单价、公式、合并、隐藏、名称或对象变化会阻断，进入优化流程。空数量或非数字数量尚未获业务政策确认，明确停止。源表记录顺序、数量值和记录数可变化。依赖锁校验 Node 可执行文件、Artifact Tool 包文件及依赖包精确版本元数据；使用本机已安装依赖，没有安装或联网。

历史输出与人工结果的所有单元格、公式和样式一致。工作簿关系 ID 在导出时重分配，但实际关联目标不变；其余包内容语义一致。结果可重新导入，预览已目视检查。文件仅放在本地案例目录，没有提交。
